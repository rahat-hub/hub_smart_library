## 🎯 প্রজেক্ট ওভারভিউ (Project Overview)

স্মার্ট লাইব্রেরি সিস্টেমটি একটি আধুনিক বিশ্ববিদ্যালয়ের দৈনন্দিন লাইব্রেরি কার্যক্রমকে সম্পূর্ণ ডিজিটাল ও পেপারলেস করতে তৈরি করা হয়েছে।
- **স্বয়ংক্রিয় লাইব্রেরি ক্যাটাগরি ও অনুসন্ধান:** যেকোনো বইয়ের নাম, লেখক বা ISBN দিয়ে দ্রুত খুঁজে বের করা।
- **সেলফ-লোকেশন ও ডিউই ইনডেক্স:** লাইব্রেরির সুনির্দিষ্ট তলা, র‍্যাক ও শেলফ নম্বর (যেমন: `সেন্ট্রাল লাইব্রেরি ২য় তলা, র‍্যাক: CS-08, শেলফ: ৩` এবং ডিউই ইনডেক্স `005.133`) প্রদর্শন।
- **ডিজিটাল স্টুডেন্ট আইডি ও আরএফআইডি পাস:** ফিজিক্যাল কার্ড ছাড়াই গেট স্ক্যানিং ও ডিজিটাল বারকোড সাপোর্ট।
- **বই ইস্যু ও রিটার্ন ট্র্যাকিং:** ১৪ দিনের ইস্যু নীতি, ডিউ ডেট ট্র্যাকিং এবং ওভারডিউ হলে দৈনিক ৳৫.০০ হারে স্বয়ংক্রিয় জরিমানা গণনা।
- **ইন-অ্যাপ পেমেন্ট গেটওয়ে:** বিকাশ, নগদ ও রকেটের মাধ্যমে সরাসরি জরিমানা পরিশোধের ডেমো সুবিধা।
- **মাল্টি-ডিভাইস রেসপনসিভনেস:** মোবাইল (<650px), ট্যাবলেট (650px - 1024px) এবং ডেস্কটপ/ওয়েব (>1024px) প্রতিটি স্ক্রিন সাইজে নিখুঁত অ্যাডাপ্টিভ ডিজাইন।

## 🏛️ আর্কিটেকচার ও স্টেট ম্যানেজমেন্ট (Architecture & State Management)

এই প্রজেক্টটিতে **MVVM (Model-View-ViewModel)** আর্কিটেকচারাল প্যাটার্ন এবং স্টেট ম্যানেজমেন্ট ও ডিপেন্ডেন্সি ইনজেকশনের জন্য **GetX** ব্যবহার করা হয়েছে।

```
┌───────────────────────────────────────────────────────────┐
│                          VIEW                             │
│   (Flutter Stateless Widgets, Responsive Layouts, UI)    │
└───────────────────────────▲───────────────────────────────┘
                            │  Observes (.obs / Obx)
                            │  Dispatches User Events
┌───────────────────────────▼───────────────────────────────┐
│                       VIEWMODEL                           │
│   (GetxControllers: Auth, Dashboard, Borrowed, Notif)     │
└───────────────────────────▲───────────────────────────────┘
                            │  Fetches / Updates
                            │  Data Logic
┌───────────────────────────▼───────────────────────────────┐
│                          MODEL                            │
│   (Dart Data Classes: BookModel, NotificationModel, etc.) │
└───────────────────────────────────────────────────────────┘
```

### কেন MVVM Pattern ব্যবহার করা হয়েছে?
1. **সেপারেশন অব কনসার্নস (Separation of Concerns):** UI লেয়ার (View) এবং বিজনেস লজিক (ViewModel) সম্পূর্ণ আলাদা। ফলে ডিজাইনে কোনো পরিবর্তন আনলে অ্যাপের মূল লজিক ক্ষতিগ্রস্ত হয় না।
2. **সহজ মেইনটেইনেবিলিটি ও টেস্টেবিলিটি (Maintainability & Testability):** কন্ট্রোলারগুলো স্বাধীনভাবে টেস্ট করা যায় (`widget_test.dart`-এ কোনো জটিল মকিং ছাড়াই পরীক্ষা সম্ভব)।
3. **কোড রিইউজেবিলিটি (Reusability):** একাধিক ভিউ (যেমন: মোবাইল ও ট্যাবলেট ভিউ) একই কন্ট্রোলার মেথড ও স্টেট শেয়ার করতে পারে।

### কেন GetX ব্যবহার করা হয়েছে?
1. **রিয়েক্টিভ স্টেট ম্যানেজমেন্ট (`.obs` & `Obx`):** `setState()` ব্যবহার করলে পুরো উইজেট ট্রি রি-বিল্ড হয়। GetX-এর মাধ্যমে শুধুমাত্র পরিবর্তিত টেক্সট বা উইজেটটি আপডেট হয়, যা অ্যাপের পারফরম্যান্সকে সর্বোচ্চ গতিশীল রাখে।
2. **ডিপেন্ডেন্সি ইনজেকশন (`Get.put` / `Get.find`):** কোনো `BuildContext` ছাড়াই যেকোনো কন্ট্রোলার ইনজেক্ট ও খুঁজে পাওয়া যায়।
3. **কনটেক্সট-লেস নেভিগেশন (`Get.toNamed`, `Get.offNamed`):** ক্লিন ইউআরএল ভিত্তিক রাউটিং সিস্টেম যা ওয়েব ও মোবাইলে মসৃণ ট্রানজিশন দেয়।
4. **সহজ ইউটিলিটি ডায়ালগ ও বটমশিট:** `Get.bottomSheet`, `Get.dialog` এবং `Get.snackbar` ব্যবহারের মাধ্যমে কোনো জটিল বয়লারপ্লেট কোড ছাড়াই সুন্দর অ্যানিমেটেড পপআপ দেখানো সম্ভব।

- **কেন Hind Siliguri নির্বাচন করা হয়েছে?**
  1. **নিখুঁত বাংলা রেন্ডারিং:** বাংলা ভাষার জটিল যুক্তবর্ণ, হ্রস্ব-ই/দীর্ঘ-ঈ কার এবং মাত্রা বিভিন্ন স্ক্রিন রেজোলিউশনে অত্যন্ত স্পষ্ট দেখায়।
  2. **বাইলিঙ্গুয়াল সামঞ্জস্য:** একই সাথে বাংলা টেক্সট এবং ইংরেজি টেকনিক্যাল টার্ম (যেমন: ISBN, Dewey Index, CSE-2021-042) কোনো অসঙ্গতি ছাড়া সুন্দরভাবে পাশাপাশি বসে।
  3. **হাই রিডাবিলিটি:** ডিজিটাল স্ক্রিনে দীর্ঘ অনুচ্ছেদ ও বইয়ের বিবরণ পড়ার ক্ষেত্রে চোখের উপর চাপ ফেলে না।

### ৭. ইন্টারেক্টিভ মডাল ও ডায়ালগসমূহ
- **ডিজিটাল আরএফআইডি পাস মডাল (Digital Pass Modal):** স্টুডেন্টের পূর্ণাঙ্গ পরিচয়পত্র, ডিপার্টমেন্ট, মেয়াদ ও প্রবেশ গেটের জন্য কিউআর কোড।
- **বই সংগ্রহের ডিজিটাল টোকেন (Issue Token Sheet):** কাউন্টারে দেখানোর জন্য ইউনিক রিকোয়েস্ট টোকেন।
- **রিটার্ন বারকোড স্ক্যানার শিট (Return Barcode Sheet):** সেলফ-ড্রপবক্সে স্ক্যান করার জন্য বইয়ের বারকোড।
- **জরিমানা পরিশোধ গেটওয়ে (Payment Gateway Modal):** বিকাশ, নগদ ও রকেটের মাধ্যমে সরাসরি ফি পরিশোধ ও রসিদ সংগ্রহের সিমুলেশন।
- **লাইব্রেরি রুলস বটমশিট (Library Rules Sheet):** বিশ্ববিদ্যালয়ের সেন্ট্রাল লাইব্রেরির নীতিমালা ও রি-ইস্যু শর্তাবলী।

## 📐 রেসপনসিভ ডিজাইন স্ট্র্যাটেজি (Responsive Strategy)

অ্যাপ্লিকেশনটিতে কাস্টম `ResponsiveLayout` উইজেট ব্যবহার করা হয়েছে যা স্ক্রিনের প্রস্থ (`MediaQuery.of(context).size.width`) অনুসারে স্বয়ংক্রিয়ভাবে লেআউট অ্যাডাপ্ট করে:

| ডিভাইস মোড | প্রস্থ (Width) | লেআউট আচরণ (Layout Behavior) |
| :--- | :--- | :--- |
| **Mobile** | `< 650px` | সিঙ্গেল কলাম লিনিয়ার ফ্লো, বটম ন্যাভিগেশন বার, অপ্টিমাইজড টাচ প্যাডিং |
| **Tablet** | `650px - 1024px` | `MaxWidthContainer(720-780px)`, গ্রিড ভিউ, বর্ধিত ফন্ট ও স্পেসিং |
| **Desktop / Web** | `> 1024px` | `MaxWidthContainer(1040-1200px)`, মাল্টি-কলাম স্প্লিট ভিউ (বামে মেইন কন্টেন্ট, ডানে সাইডবার/হেল্পডেস্ক) |

## 🚀 রান ও সেটআপ গাইড (Getting Started & Setup)

### পূর্বশর্ত (Prerequisites):
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (সংস্করণ `3.13` বা তদূর্ধ্ব)
- Dart SDK (`^3.13.7`)
- Android Studio / VS Code (Flutter ও Dart প্লাগইন সহ)
- Chrome ব্রাউজার (ওয়েবে চালানোর জন্য) অথবা যেকোনো মোবাইল এমুলেটর / ফিজিক্যাল ডিভাইস

### ইনস্টলেশন ধাপসমূহ:

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/your-username/hub_smart_library.git
   cd hub_smart_library
   ```

2. **ডিপেন্ডেন্সি প্যাকেজগুলো ইনস্টল করুন:**
   ```bash
   flutter pub get
   ```

3. **অ্যাপ্লিকেশনটি রান করুন:**
   - **ডিফল্ট ডিভাইসে:**
     ```bash
     flutter run
     ```
   - **Chrome ওয়েব ব্রাউজারে:**
     ```bash
     flutter run -d chrome
     ```
   - **নির্দিষ্ট মোবাইলে (Android/iOS):**
     ```bash
     flutter run -d <device-id>
     ```

4. **অটোমেটেড টেস্ট রান করুন:**
   ```bash
   flutter test
   ```
